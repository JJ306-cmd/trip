# 국내여행 동선

지역을 검색하면 명소와 맛집을 추천하고, 고른 장소로 일자별 동선을 만들어 지도에 보여줍니다.

## 실행
1. Node.js 18 이상을 설치합니다. (https://nodejs.org)
2. 이 폴더에서 `npm start` 를 실행합니다. 따로 설치할 패키지는 없습니다.
3. 브라우저에서 http://localhost:3000 을 엽니다.

키가 없으면 **예시 모드**(경주만, 가상 식당, 추정 이동시간)로 동작합니다.

## 실제 데이터 연결
1. https://developers.kakao.com 에서 앱을 만듭니다.
2. 앱 설정에서 **카카오맵 사용 설정을 ON** 으로 바꿉니다. 무료 쿼터는 처음 활성화한 앱에만 주어지니 실제로 쓸 앱에서 켜세요.
3. JavaScript 키의 사이트 도메인에 `http://localhost:3000` 을 등록합니다.
4. `.env.example` 을 `.env` 로 복사해 REST API 키와 JavaScript 키를 넣고 다시 실행합니다.

REST 키는 서버에서만 사용합니다. `.env` 는 GitHub에 올리지 마세요.

## AI 맞춤 추천
`.env` 에 `AI_PROVIDER`(openai 또는 gemini)와 해당 키를 넣고 서버를 다시 실행하면 추천 목록 위에 입력칸이 나타납니다.
취향을 적고 누르면 AI가 검색된 후보 중에서 골라 체크합니다. 동선 계산은 AI가 아니라 `planner.js` 가 합니다.
카카오 키 없이 AI 키만 넣어도 경주 예시 후보로 시험할 수 있습니다.
호출할 때마다 요금이 생길 수 있으니 AI 서비스에서 사용 한도를 설정하세요.

## 직접 넣거나 고칠 곳
코드에서 `★` 를 검색하면 모두 찾을 수 있습니다.

| 파일 | 내용 | 필수 |
|---|---|---|
| `.env` | 카카오 REST 키, JavaScript 키 | 필수 |
| `.env` | TourAPI 키 (명소 사진) | 선택 |
| `.env` | AI 종류와 키 | AI 사용 시 |
| `extras.js` | 블로그 후기 (빈 자리, 직접 구현) | 선택 |
| `public/planner.js` | 체류시간, 식사시간 | 선택 |

## 추천과 동선의 기준
- 추천 순서는 카카오 검색 결과 순서입니다. 평점·리뷰 수 기반 순위가 아닙니다.
- 방문 순서는 직선거리 추정 이동시간과 식사시간(점심 12시, 저녁 18시 전후)으로 계산합니다.
- 정해진 순서에 대해 자차는 카카오모빌리티, 대중교통은 카카오맵 경로 API로 시간을 가져옵니다.
- 자차를 고르면 장소의 주차 가능 여부(TourAPI 키 필요)를 보여주고, 가능이 확인되지 않으면 1km 안 공영주차장을 안내합니다. 요금, 운영시간, 빈자리는 알 수 없습니다.
- 영업시간과 휴무일은 반영하지 않습니다.

대중교통은 구간별 소요시간과 승하차 정류장을 보여줍니다. 여행지 안의 배차 시간표와 실시간 도착은 포함하지 않습니다.

## 동행 유형과 날씨
- 가족·커플·친구·혼자에 따라 검색어와 하루 기본 명소 수(2·3·4·3곳)가 달라지고, AI에도 전달됩니다. 장소의 적합성을 검증한 것은 아닙니다.
- 날씨는 data.go.kr 에서 "기상청_단기예보 조회서비스"를 활용신청해야 나옵니다. `TOUR_API_KEY` 를 사용합니다. 가까운 며칠만 예보가 있습니다.

## 코스 따라가기
동선을 만든 뒤 "안내 시작"을 누르면 내 위치와 다음 장소까지의 직선거리를 보여줍니다. 100m 안에 들어오면 다음 장소로 넘어갑니다.
회전·음성 안내는 카카오맵 링크를 이용합니다. 휴대폰에서 쓰려면 HTTPS 로 배포해야 합니다. 위치는 서버로 보내지 않지만, 지도와 카카오맵 링크는 해당 서비스의 정책을 따릅니다.

## 기차·고속버스·시외버스 시간표
1. data.go.kr 에서 "국토교통부_(TAGO)_열차정보", "고속버스정보", "시외버스정보"를 각각 활용신청합니다.
2. `npm run check-tago` 로 세 가지가 되는지 확인합니다. 실패하면 `tago.js` 위쪽의 호출 이름을 활용가이드와 맞춥니다.
3. `npm start` 후 이동수단에서 **대중교통**을 고르고 화면의 "오가는 기차·고속·시외버스 시간표"를 펼칩니다.

직행편만 보여줍니다. 시외버스는 오늘 출발편만 조회됩니다. 예매와 잔여 좌석은 지원하지 않습니다.

## 배포 (Render 예시)
1. GitHub 에 **비공개** 저장소를 만들고 GitHub Desktop 으로 올립니다. 웹에서 파일을 끌어 올리면 `.gitignore` 가 적용되지 않으니 `.env` 를 올리지 않도록 주의하세요.
2. https://render.com 에서 New > Web Service 로 저장소를 연결합니다.
   - Language: Node / Build Command: `npm install` / Start Command: `npm start`
   - Health Check Path: `/healthz`
3. Environment 에 `.env` 의 값들을 하나씩 넣고 `HOST=0.0.0.0` 을 추가합니다. **PORT 는 넣지 않습니다.**
4. 발급된 `https://...onrender.com` 주소를 카카오 JavaScript 키의 사이트 도메인에 추가합니다.
5. `/privacy` 의 ★직접입력 부분을 채워 다시 올립니다.

무료 인스턴스는 15분 동안 접속이 없으면 잠들고 다시 켜지는 데 약 1분이 걸립니다.
호출 제한 횟수는 재시작하면 초기화되므로, AI 서비스에서도 사용 한도를 설정하세요.
